# Lista de pruebas

Marca cada prueba con `[x]` cuando pase. Si falla, crea un Issue en GitHub con pasos para repetirlo y una captura.

## Catálogo
- [ ] Se puede dar de alta un producto con nombre, foto, precio y categoría
- [ ] Se puede editar un producto y el cambio se ve en el catálogo
- [ ] Se puede eliminar un producto (pide confirmación)
- [ ] El filtro por categoría y el buscador funcionan

## Carrito y pago
- [ ] Agregar, sumar, restar y quitar productos del carrito
- [ ] No deja agregar más unidades de las que hay en existencia
- [ ] Al confirmar la compra se crea el pedido y se vacía el carrito

## Stock
- [ ] Al comprar, las existencias bajan
- [ ] Aparece aviso cuando un producto se agota
- [ ] Un producto agotado no se puede agregar

## Panel del vendedor
- [ ] El pedido nuevo aparece en la tabla
- [ ] Se puede cambiar el estado del pedido
- [ ] Las alertas de stock bajo se actualizan

## Vista 3D
- [ ] La escena gira con el mouse y con el dedo en el celular
- [ ] "Ver por dentro" separa las piezas
- [ ] Tocar una pieza muestra su precio y existencias

## Dispositivos
- [ ] Computadora (Chrome)
- [ ] Celular Android
- [ ] iPhone
